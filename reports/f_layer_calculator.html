F-layer caveat: the F-layer formula above (subtract everything from F-wall) assumes no prefetch credit — it applies to the first F layer, which has no predecessor to hide IO behind. Non-first F layers can prefetch idx_io + kv_io into the previous (S) layer's wall, getting a budget similar to S layers. Only the first F layer pays the full serial cost shown here.

S-layer: KV is prefetched into the previous layer's wall, but the SSD bus is shared — S can't start its KV read until the prior layer's KV read finishes. So the slack is prev_wall − prev_kv_io_time, not the full prev wall. (HBM-resident indexer: HBM is a memory bus — bandwidth applies, IOPS does not.)

Caveats

  • The avg-layer formula assumes steady-state pipeline throughput. The startup / drain overhead is ≈ 1 layer of (io + cmp), so a single-token TPOT will overshoot by ~1 layer's worth.
  • F vs S split assumes block_a, block_c, MoE, kv_io are identical between F and S; only idx_io and idx_comp differ. idx_comp is tiny (≤ 0.04 ms / layer), so the gap ≈ idx_io.
  • HBM bandwidth here uses GB = 2^30 and HBM_BW = 1384 GB/s, matching experiments/analytical_layer.py.
  • For mixed regimes (some F, some S) the answer is for the F layer specifically; for DSA both F-count = L and S-count = 0 so the avg equals F directly.
