Caveats

  • The avg-layer formula assumes steady-state pipeline throughput. The startup / drain overhead is ≈ 1 layer of (io + cmp), so a single-token TPOT will overshoot by ~1 layer's worth.
  • F vs S split assumes block_a, block_c, MoE, kv_io are identical between F and S; only idx_io and idx_comp differ. idx_comp is tiny (≤ 0.04 ms / layer), so the gap ≈ idx_io.
  • HBM bandwidth here uses GB = 2^30 and HBM_BW = 1384 GB/s, matching experiments/analytical_layer.py.
  • For mixed regimes (some F, some S) the answer is for the F layer specifically; for DSA both F-count = L and S-count = 0 so the avg equals F directly.
