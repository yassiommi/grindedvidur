Per-layer compute model (ms — defaults: FP8 + MLA absorption, TP=2)
Compute is modeled as cmp_per_layer = c_flat + c_per_bs × bs. At BS=1 FP8 TP=2 the analytical model gives ≈ 0.24 ms; at BS=6 it gives ≈ 0.49 ms — the linear fit (0.19 + 0.048·BS) is within ~3% across the BS=1–24 range.
If you change TP, scale both c_flat and c_per_bs roughly by (2/TP); FP16 doubles both.
These are compute-only per-layer times. The model uses F = max(io_F, compute_F) and S = max(io_S, compute_S) where compute = block_a + topk + attn + moe (S drops topk). TP-shard the compute by dividing by TP if you want a per-rank view; defaults assume already-sharded.

Model — quick reference

kv_io = max( kv_bytes / SSD_BW , kv_iops / SSD_IOPS , SSD_FLOOR ) — whichever of bandwidth, IOPS, or floor is the binding constraint dominates.
F = max(idx_io + kv_io, compute_F) — F-layer IO chain is idx_io → topk → kv_io; we sum the IO and take the max against compute.
S = max(kv_io, compute_S) — S-layer reuses prior F's top-k, no indexer IO of its own.
TPOT = avg_layer × L — each token traverses all PP stages sequentially. PP divides memory per rank, not per-token latency.
Forward mode is direct. Reverse modes binary-search over the unknown until TPOT matches the target.
